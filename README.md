# 媽祖遶境即時追蹤系統

這是一個用於追蹤媽祖遶境隊伍即時位置的網頁應用程式。

## 核心功能

1. **即時路線追蹤**
   - 互動式地圖顯示遶境隊伍的即時位置
   - 從 API 接收 GPS 位置資料
   - 即時更新位置標記

2. **首頁**
   - 簡潔的活動介紹
   - 即時位置地圖（與功能 1 整合）
   - 簡潔的設計風格

## 技術規格

- 前端框架：React
- 地圖功能：Leaflet
- 即時更新：WebSocket 或 REST API
- 響應式設計：支援各種裝置尺寸
